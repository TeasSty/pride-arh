# Design concept — ПРАЙД барбершоп, Архангельск

## Client / project

- Name: ПРАЙД барбершоп, Архангельск
- Date: 2026-11-12
- Niche: независимый мужской барбершоп / клуб приятелей в северном городе
- Concept-ID: 2026-11-12-pride-peer-protocol-v1
- Composition-archetype: workshop-protocol
- Forbidden-for-this-niche: dark+gold quiet luxury; черепа / barber-pole клише; гаражный неон; франшизный «мужской дух»; hero + 3 feature-cards с иконками; purple/indigo; cream+#F4F1EA+terracotta+serif
- Delta-from-previous: n/a (first concept)

## Niche fingerprint

- Ритуал: запись → подъём на 3 этаж ТЦ «Вертикаль» → кресло → стрижка/борода → чай/кофе и разговор на равных → выход с формой
- Материалы: машинка и сталь насадок, опасная бритва (королевское бритьё), глина/паста для укладки, пелерина, чашка кофе
- Место / свет: северный Архангельск, холодный дневной свет; интерьер внутри ТЦ, не уличный storefront с pole
- Vernacular: «приятели», «без подхалимства», «стрижём и бреем», «отец+сын», лист записи
- Сенсорика: жужжание машинки, запах кофе и стайлинга, спокойный тон (не вечеринка)

## Unique thesis

1. Mood: спокойная северная уверенность — тёплый интерьер против холодного внешнего света, ремесло без VIP-театра
2. Type rationale: плотный гротеск (Onest) для бренда и протокола; Golos Text для живой русской речи; IBM Plex Mono для цен, времени и номеров как бланк записи / номер насадки
3. Palette logic: северное окно `#C9D2DA`, чернила фартука `#1B232A`, сталь `#8B959F`, кофе/дерево `#A56A3A`, пар/полотенце `#E6E2DA`; золото логотипа только в марке
4. Composition: workshop-protocol — вертикальный ритуал визита 01–04, асимметричные врезки работ, прайс-ledger, мастера как выбор человека
5. Motion: медленный; появление номеров протокола, сдвиг ленты работ, акцент CTA
6. Main gesture: «Северный протокол приятеля» — сайт как нумерованный визит, не шаблонный lead-gen
