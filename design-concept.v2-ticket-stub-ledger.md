# Design concept — ПРАЙД барбершоп, Архангельск

## Client / project

- Name: ПРАЙД барбершоп, Архангельск
- Date: 2026-11-12
- Niche: независимый мужской барбершоп / клуб приятелей в северном городе
- Concept-ID: 2026-11-12-pride-appointment-ledger-v2
- Composition-archetype: ticket-stub-ledger
- Forbidden-for-this-niche: dark barbershop hero; Tilda funnel hero→features→prices→form; black/gold luxury; черепа/pole; 3 feature-cards; purple/indigo; cream+#F4F1EA+terracotta+serif
- Delta-from-previous: archetype workshop-protocol → ticket-stub-ledger; убран тёмный full-bleed hero и секционный лендинг; страница = один бланк записи/талон; палитра светлая «бумага на северном свете»; тип — форма/квитанция, не marketing sections

## Niche fingerprint

- Ритуал: запись → 3 этаж ТЦ «Вертикаль» → кресло → стрижка/борода → чай/кофе → выход
- Материалы: бланк записи, машинка/насадки с номерами, бритва, глина, чашка кофе
- Место / свет: холодный северный день, интерьер ТЦ
- Vernacular: лист записи, прайс на стене, «без подхалимства», «приятели»
- Сенсорика: бумага, ручка, жужжание машинки, кофе

## Unique thesis

1. Mood: канцелярия барбершопа — спокойный северный бланк, не клубный постер
2. Type: Onest для штампа PRIDE; IBM Plex Mono для полей/цен/времени; Golos Text для коротких живых фраз
3. Palette: бумага `#E6E2DA` на северном фоне `#B8C3CD`; чернила `#1B232A`; кофе `#A56A3A` только для штампов/линеек; без тёмного hero
4. Composition: ticket-stub-ledger — весь сайт один талон/бланк с отрывным корешком «Записаться»
5. Motion: почти нет; лёгкое появление строк бланка
6. Main gesture: сайт = талон записи PRIDE, а не лендинг услуг
